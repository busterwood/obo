# legacy

`obo-on-obx.obx` is obo's first compiler, written in obx and built by `obx/obxc`.
The compiler is now `src/obo.obo`, written in obo and built by `seed/obo`, so this
file is kept for reference only: nothing builds or tests with it.

The `tools/` scripts here are the one-off patch scripts that made the changes to this
file, milestone by milestone. They patch `obo-on-obx.obx`, which lives here now.
