# obx/compiler: the obx compiler

The obx compiler, written in obx: it compiles obx to C (gcc builds the
binary) or, with `--native`, straight to an x86-64 ELF executable. Since
2026-11-02 it is the only obx compiler: the language is changed here, in the
spec ([../SPEC.md](../SPEC.md)) and in the tests together. It compiles itself
to a fixed point, and its own C is checked in as the seed, so a build needs
only gcc.

    obx/compiler/build.sh                                   # out/obxc from the C seed (gcc only)
    obx/compiler/reseed.sh                                  # after a compiler change: rebuild seed/obxc.c, check the fixed point
    python3 obx/tools/seed_check.py                         # the fixed point without writing the seed (the gate's first step)
    ./obxc file.obx [-o out] [--run] [--emit-c] [-L root] [-- args]   # gcc builds the C
    ./obxc file.obx --native [-o out]                       # x86-64 ELF, no gcc
    ./obxc --emit-c file.obx...                             # the C of each program, in `== path` sections
    ./obxc --dump-ast file.obx...                           # the parse tree
    ./obxc --dump-types file.obx...                         # what sema resolves
    python3 obx/compiler/fuzz.py [-n N] [--seed S] [--cc]   # mutants must compile or fail cleanly
    obx/tools/gate.sh quick                                 # the suites (obx/tests/README.md)

A compile error prints `file:line: message` and exits 1 (one error, then
stop). gcc runs with `-O2 -w`; an `extern "lib"` links `-llib` (or the
library by its full path when only `libX.so.N` exists). Run a program with
`OBX_CHECK=1` to make a leak (live objects at exit) exit 5. out/obxc finds
the library at `../../lib` (obx/lib); set `OBX_LIB` to use another.

## History

The compiler began as a port of the Python reference compiler (`ref/`, stage
2 of [../PLAN.md](../PLAN.md)), module by module with the same algorithms, and
was checked mechanically against it: identical `--dump-ast`, `--dump-types`
and C (or error message) on all 2,427 test files and on tens of thousands of
mutants, with no leaks; ref built stage 1, and stages 2 and 3 wrote ref's C.
The obx code came out about twice the lines of the Python, mostly for what obx
lacks (tuples, exceptions, unbounded integers, Python's `repr`). ref was
retired on 2026-11-02 to [../../archive/obx-ref/](../../archive/obx-ref/README.md),
with its comparison script `run_compare.py`; its own tests became
`../tests/compiler/`, its runtime `rt.h` moved here, and the comparison's mutant
generator is `fuzz.py`. The full record of the port is in the git history of
this file.

## Design

**The AST is an arena, not a tree of boxed closed types.** Every node is a
`Node` value record in `Ast.nodes`, named by its index; a list is a handle
into `Ast.items` (its length, then the element indexes). A node has a kind
(`N_*`), a line, flags, three strings (`s`, `t`, `u`) and five int slots
(`a` to `e`) whose meaning per kind is listed next to the `N_*` constants.
The reasons:

- Borrows are second class (SPEC 4.5, 10): a symbol table, a declaration
  record or a work list cannot hold a `&Expr` into a boxed tree. The later
  stages refer to AST nodes from everywhere (a FnDecl keeps its body, a
  generic function is rendered once per instance, a template refers back to
  its node); with an arena that reference is an `int`, a copy value that can
  be stored anywhere.
- The tree is not changed after parsing, but sema and check keep per-node
  facts (types, resolved declarations); with indexes those are side arrays
  indexed by the node.
- One growing array instead of one heap object per node, and no recursive
  drop of a deep tree.
- A boxed tree in obx would be walked by `match`, which binds owned fields as
  borrows: natural for a single walk, but every node a pass wants to keep
  would have to be found again by a path.

The cost is that field names are positional (`a`, `b`, ...) and the kinds are
not checked by the type system; accessor functions per kind can be added when
sema needs them. Kinds are `int` constants rather than a closed type because
`match` arms cannot name constants and a closed type of ~55 payload-free
variants would need an `eq` method or a `match` for every comparison.

**Tokens** are value records `{k, op, line, s, v}`. Names, keywords and
symbols share their bytes with the source (a substring is not a copy), as do
string literals without escapes. Integer literals keep their value as decimal
digits of any size (the range check is sema's), so the lexer converts hex and
binary digits to decimal itself.

**Errors** stop the compiler: `fail(fname, line, msg): never` prints `file:line:
message` (to stderr, or as `error: ...` on stdout when several files are
dumped, so that it stays in order) and exits 1. A run over many files
therefore stops at the first error; a caller starts the compiler again from the
next file.

**sema's tables.** Modules, type declarations, variants, functions,
constants, globals and type parameters are value records in arrays of one
`Program`, named by index; a scope maps a name to a kind and an index. A type
is an int: types are interned (hash-consed) in `Program.tys` with their lists
in `Program.tlists`, so type equality is `==` on ints, and substitution builds
new ids. An environment (type parameters to types) is a flat list of pairs,
with -1 for `Self`. A folded constant is a `CVal` record. An error in a
constant's initializer is reported wrapped ("the initializer of const C is not
constant (...)", nested for constants that refer to constants); with no
exceptions, `Program` keeps a stack of the constants being folded and the error
function applies the wrappers itself. `is_copy` on a value type that contains
itself (before the inline-cycle check) stops at a depth limit of 5,000. A
module's C prefix replaces every non-ASCII-alphanumeric byte with `_`.

**Nesting depth.** The parser counts its nesting (statements, types,
expressions, unary operators) and stops with `file:1: the program is nested too
deeply` above 3,000, well within the C stack.

**check, emit and lower.** Variables and temporaries are tables in the `Checker`
(a value's root is an int: a Var, `-2 - tmp`, or -1) and a place's path is a
str of NUL-ended elements. The checker writes each function as a template
(`tmpl.obx`): trees of C-shaped expressions and statements in one arena, with
holes for whatever depends on the type arguments. The holes of the function
being checked live on the `Checker` and are taken by `checkFn` into the
function's `Tmpl` (lines, holes, lifted closures). A hole is a `Hole` value
record; its nested trees (a drop's place, an interface method's receiver and
arguments) may hold holes themselves, filled before the outer glue is named.
Every C name is numbered in the order it is first asked for, which is the
order of the old C text (holes are filled in that order), so the numbering
depends on the order of those requests. The pseudo expected types of a slice
are `EXP_SLICE` and `EXP_MUTSLICE` (-2, -3). The errors of a global's
initializer get a prefix, `Program.gwrap`, that the error function adds. The
drop glue's case walk takes a mode rather than a function, as a closure cannot
capture the `mut &Emitter` it would call. emit hands each function's lines,
with what their holes stand for, to `lower`, which builds the IR: a type hole
is a C type name (`S3_foo*`, `fn5`) that lower resolves, and a flat line
stream (`if (c) {`, `} else {`, `}`) is read back into nested statements.
Both backends start from the IR: `cgen` prints it as C, `x64gen` compiles it.
The driver runs gcc with `system()` (an extern; the library has no process
spawning) on shell-quoted words, in a `mkdtemp` directory.

**Tasks** (SPEC 16) are library code (`lib/task.obx`) over runtime helpers
in both runtimes; the compiler knows four things. A module loaded from a
library root has `Module.isLib`, and only there do `intoPtr` and `fromPtr`
exist (`Checker.rawPtr`: a cast that moves a boxed value to a `ptr` and
back). `Program.shared` is the `TypeDecl` of `task.Shared`: `isPod` is false
for its instances, so emit writes dup glue that calls `rt_sh_dup(v.f_p)` and
drop glue (`direct`) that calls `rt_sh_drop(v.f_p)`; both are declared in
`native/obxrt.h`, which lower reads for either backend. The boxing of a
task's argument and result per instance is `task`'s own generic code
(`run[A, T]`, `dropCell[T]`), passed to the runtime as `extern fn` values.
`Program.where` is the `TypeDecl` of `std.Where` (SPEC 15, a call site):
`Checker.implicitWhere` appends the argument to a direct call (a function,
an associated function or a method; `SK_FN` with a declaration in a module
with `isLib`) that leaves out a last parameter of that type, before `call`
checks the arguments, as an already checked value: the record literal
`{.f_p = "file:line"}`, the same static string as the `w` of a run-time
check (`Checker.W`). task's functions that park, and `with`, pass it to the
runtime, which keeps the open `with` blocks as a stack in the `Shared`
blocks and each task's park location, for the exit 13 and 14 messages.

## Status

- Every suite passes with the seed-built compiler (`obx/tools/gate.sh full`):
  the conformance suite, the compiler tests, the library tests and the
  red-team corpora under ASan+UBSan; no leaks (`OBX_CHECK=1`).
- Seed: `seed/obxc.c` is the compiler's own C at the fixed point (stage 2 and
  stage 3 write the same C). `build.sh` builds `out/obxc` from it with gcc
  alone; `reseed.sh` rebuilds the seed from the sources with `out/obxc` and
  checks the fixed point. Run `reseed.sh` and commit the seed with every
  compiler change; the gate fails while the seed is stale. A language change
  the compiler's own source uses takes two rounds: implement it and reseed,
  then use it.
- Speed: the compiler itself to C (`--emit-c`) in 0.19 s, natively
  (`--native`, a complete executable) in 0.23 s, both with the gcc-built
  out/obxc (2026-11-03). A gcc build is then mostly gcc (9 s for the compiler).
- Native: `obxc --native` writes an x86-64 ELF without gcc
  (design/native.md): static, or dynamically linked when the program calls C
  functions the native runtime does not have (libm, sqlite3, pq, ...). The
  compiler builds itself natively to a fixed point:
  `obx/tools/native_selfbuild.sh`.
